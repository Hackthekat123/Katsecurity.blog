The application dynamically loads Microsoft.DiaSymReader.Native.amd64.dll using LoadLibraryExW without specifying an absolute path. The DLL is not present in System32, and the application directory is writable via SMB. This allows DLL search order hijacking by placing a malicious DLL in the application root directory.
